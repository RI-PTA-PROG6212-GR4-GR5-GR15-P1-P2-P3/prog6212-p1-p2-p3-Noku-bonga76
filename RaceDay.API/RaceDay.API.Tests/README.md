# RaceDay.API.Tests

This project contains automated unit tests for the RaceDay API.

## Test Coverage

- Controller and service functionality
- Authentication and authorization
- Event management
- Role-based access restrictions
- Participant enrolments

## Running Tests

Run the following command from the repository root:

`dotnet test RaceDay.API.Tests/RaceDay.API.Tests.csproj`

The tests are intended to run automatically through GitHub Actions.
